# API Reference {#mainpage}

This is the front page of the API documentation generated by the `docs` target:

```sh
cmake/idi/tools/docs.sh --open        # or: cmake --build build --target docs
```

Replace this text with an introduction to your project: what it does, where to start, and a
short usage example. Other Markdown files in `docs/` become extra pages.

The reference pages are generated from the comments in the component headers:

- shared library builds document each component's `include/<project>/public/` headers (the exported API);
- static library and executable builds document all of `include/<project>/`.

See the Docs section of the project README for the settings (`IDICMAKE_DOCS_*`, `DOXYGEN_*`).
